# Forest Asset Credits

These assets are included locally so the game does not need to fetch models or textures from an asset host at runtime.

## Fir Sapling

- Asset: [Fir Sapling](https://polyhaven.com/a/fir_sapling)
- Model authors: Rico Cilliers (modeling), Rob Tuytel (photography)
- License: [CC0](https://polyhaven.com/license)
- Local file: `fir_sapling.glb`
- Source format: 1K glTF, optimized and packed as GLB with meshoptimizer compression.

## Forest Ground 01

- Asset: [Forest Ground 01](https://polyhaven.com/a/forrest_ground_01)
- Author: Rob Tuytel
- License: [CC0](https://polyhaven.com/license)
- Local file: `forest_ground_diffuse_1k.jpg`

## Island Tree 02 Leaves

- Asset: [Island Tree 02](https://polyhaven.com/a/island_tree_02)
- Authors: Rico Cilliers (cleanup and processing), Rob Tuytel (scanning and processing)
- License: [CC0](https://polyhaven.com/license)
- Local files: `island_tree_leaves_diff_1k.png`, `island_tree_leaves_alpha_1k.png`
